## 1. Introduction
The project involved practical network security exercises using Kali Linux and Metasploitable2 in an isolated virtual environment.

## 2. Objectives

- Discover active hosts.
- Identify open ports and services.
- Perform vulnerability assessment.
- Analyze network traffic.
- Configure and test firewall rules.

## 3. Tools and Technologies
- Kali Linux
- Metasploitable2
- VirtualBox
- Nmap
- OpenVAS
- Wireshark
- iptables
- Netcat
- hping3

## 4. Practical Implementation

### Reconnaissance
Collected domain, DNS and network information.

### Network Scanning
Used Nmap for host discovery, port scanning, service detection and OS detection.

### Vulnerability Assessment
Configured OpenVAS and initiated vulnerability feed synchronization.

### Traffic Analysis
Captured and analyzed HTTP, FTP, DNS and TCP/UDP packets using Wireshark.

### Firewall Configuration
Created and tested basic allow and deny rules using iptables.
