To capture and analyze network traffic and understand different network protocols.

## Tool

- FTP

## Activities

1. Started Wireshark.
2. Selected the appropriate network interface.
3. Started packet capture.
4. Generated traffic in the isolated lab.
5. Applied protocol-specific display filters.
6. Observed packet details and communication patterns.
